## sftp-ubuntu

### Architecture Overview

```
Internet
    │
    ▼
Elastic IP (static public IP)
    │
    ▼
EC2: sftp-ubuntu  (t3.large, Ubuntu 22.04 LTS)
  ├── Root EBS:  100 GB  gp3  (encrypted)
  └── Security Group: port 22 inbound (SSH/SFTP)

AWS Secrets Manager
  └── sftp-ubuntu/ssh-private-key  (RSA 4096-bit private key)
```

### Resources Created

| Resource | Details |
|---|---|
| `aws_instance` | `sftp-ubuntu` · t3.large · Ubuntu 22.04 LTS |
| `aws_eip` | Static public Elastic IP |
| `root_block_device` | 100 GB · gp3 · encrypted |
| `aws_security_group` | Inbound TCP 22 (SSH/SFTP) · all outbound |
| `aws_key_pair` | RSA 4096-bit key pair |
| `aws_secretsmanager_secret` | `sftp-ubuntu/ssh-private-key` |
| `tls_private_key` | RSA 4096-bit key generated by Terraform |

### Prerequisites

1. [Terraform ≥ 1.5](https://developer.hashicorp.com/terraform/downloads) installed
2. AWS CLI configured with the `CoreProdWorkloadAccount` profile:
   ```bash
   aws configure --profile CoreProdWorkloadAccount
   ```
3. Your VPC ID and a **public subnet** ID in `ap-south-1`

### Usage

#### 1. Fill in required values

Edit `sftp-ubuntu/terraform.tfvars` and replace the placeholder VPC / subnet IDs:

```hcl
vpc_id    = "vpc-xxxxxxxxxxxxxxxxx"   # your VPC in ap-south-1
subnet_id = "subnet-xxxxxxxxxxxxxxxxx" # a public subnet in ap-south-1
```

To find them:
```bash
aws ec2 describe-vpcs    --region ap-south-1 --profile CoreProdWorkloadAccount
aws ec2 describe-subnets --region ap-south-1 --profile CoreProdWorkloadAccount \
  --filters "Name=map-public-ip-on-launch,Values=true"
```

#### 2. Initialise Terraform

```bash
cd sftp-ubuntu
terraform init
```

#### 3. Plan

```bash
terraform plan -out=tfplan
```

#### 4. Apply

```bash
terraform apply tfplan
```

#### 5. Retrieve the SSH private key and connect

```bash
# Retrieve private key from Secrets Manager
aws secretsmanager get-secret-value \
  --secret-id sftp-ubuntu/ssh-private-key \
  --profile CoreProdWorkloadAccount \
  --region ap-south-1 \
  --query SecretString --output text \
  | jq -r '.private_key' > sftp-ubuntu.pem

chmod 400 sftp-ubuntu.pem

# SSH into the instance
ssh -i sftp-ubuntu.pem ubuntu@<public_ip>

# SFTP into the instance
sftp -i sftp-ubuntu.pem ubuntu@<public_ip>
```

> **Tip:** The public IP is shown in the `instance_public_ip` Terraform output after apply.

#### 6. Destroy (when no longer needed)

```bash
terraform destroy
```

### Security Recommendations

- **Restrict SSH/SFTP CIDRs** – update `allowed_ssh_cidrs` and `allowed_sftp_cidrs` in `terraform.tfvars` to your specific IP ranges instead of `0.0.0.0/0`.
- **Enable MFA delete** on the S3 bucket if you use a remote Terraform state backend.
- **Remote state** – consider storing `terraform.tfstate` in an S3 bucket with DynamoDB locking for team collaboration.
- **KMS encryption** – optionally specify a KMS key ARN for EBS and Secrets Manager encryption at rest.
